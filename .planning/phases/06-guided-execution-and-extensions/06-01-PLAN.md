Create `Sources/PremiseTelemetry/EngineEvent.swift`:
```swift
import PremiseCore

/// Observable engine lifecycle events for telemetry consumers.
/// These events are purely observational and MUST NOT affect
/// replay semantics or trace content.
public enum EngineEvent: Sendable {
  case runStarted(propertyID: PropertyIdentity, runIndex: Int)
  case replayAttempt(propertyID: PropertyIdentity, traceEntryCount: Int)
  case shrinkStep(propertyID: PropertyIdentity, iteration: Int)
  case runFinished(propertyID: PropertyIdentity, passed: Bool, runCount: Int)
}
```

Create `Sources/PremiseTelemetry/TelemetrySink.swift`:
```swift
/// Protocol for observing engine events. Implementations MUST be
/// side-effect-free with respect to engine state (no mutation of
/// traces, configs, or results).
public protocol TelemetrySink: Sendable {
  func record(_ event: EngineEvent) async
}
```

Create `Sources/PremiseTelemetry/TelemetryRelay.swift`:
An actor that holds `[any TelemetrySink]`, provides `register(_ sink:)` and `emit(_ event:)` methods. `emit` fans out to all registered sinks. The actor is `public` and `Sendable` by virtue of being an actor.

Remove the placeholder stub file from `Sources/PremiseTelemetry/` after creating the real files.

- Test sidecar semantics: run a property via Runner, emit events manually alongside, verify RunResult is unaffected by telemetry emission
- Test empty relay (no sinks) emits without crash

Do NOT call `LoggingSystem.bootstrap` anywhere. Do NOT store telemetry data inside ChoiceTrace or FailureRecord.
