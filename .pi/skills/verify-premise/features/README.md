# Premise verification map

Read the parent skill first. Each recipe describes a user entry point; do not report one entry point verified merely because another passed. Use a unique scratch directory and retain action, output, exit status, and side effects in the separate evidence directory.

---
## Features

- [Consumer property](property.md): generate values and run a Swift Testing property from a separate SwiftPM package.
- [Generate a property skeleton](ghostwriter.md): invoke the SwiftPM ghostwriter command and inspect its output.
- [Inspect a replay trace](replay.md): decode a real replay artifact or reproduction blob using the SwiftPM plugin.

Report each journey separately. Remote package installation, stateful testing, persistence, fuzzing, and Apple device execution are not covered by this initial map. The experimental macro is excluded from this version.
